One-time 2-minute Google Cloud OAuth setup
  1. Open Google Cloud Console → enable Google Calendar API.
  2. Go to Google Auth Platform → Audience → add your Gmail under Test users.
  3. Go to Clients → Create Client → Web application and add this exact Authorized Redirect URI:
    http://localhost:8000/api/google/callback
  4. Paste your Client ID and Client Secret below (or in .env) and click Connect!
